# Independent Campus application and scene owners

App owns one Campus composition, fixed thirteen-tab shell, scene/world/viewer
bindings, optional Dev contributions, shared build metadata and app release tools.
The public `mountCampusApp` receives a catalogue and default scene from its route.
It has no Minneapolis, Saint Paul or Twin Cities content import. Report-only
startup precedes native preparation. Retirement closes composition and pending
scene/session work before releasing borrowed native resources.

Minneapolis owns 48 authored panoramas; Saint Paul owns 12. Membership comes
from named public groups and explicit retired-stop placement prose. Each retains
original IDs, captions, descriptions, links, uncertain positions, unknown height,
unaligned north, sameImage aliases and credits. Twin Cities owns exact child
source pins, original entity/group order, overview and four deliberate cross-campus
directions. Earth Scenes owns checked child/aggregate production and reference
validation. Authored source JSON is not a generated Scene v1 manifest.

Tour owns a static three-card selector and runtime-free workspace/routing data.
The club owns the homepage and one canonical Pages assembly at `/tour/`,
`/tour/minneapolis/`, `/tour/st-paul/` and `/tour/twin-cities/`. Exact selector and
three compiled scene artifacts are verified before an additive ignored overlay.
No sibling source is vendored. Root worker scope, report-only/explicit reload
behavior, older bundles and legacy `/tour/twin-cities/scene.json` remain required.

One [shared media descriptor](../content/shared-legacy-media-release.json) retains
the 60-image preview sheet/cell map. Its measured sheet hash is an exact known
input; the full corpus artifact and immutable public transport remain unsealed.
No photos were moved, copied, scanned or reencoded during source extraction.
The legacy scene bytes and resource paths remain unchanged. The private backup
is untouched and is not a setup/build/runtime dependency.

Optional YouVisit authoring is exported from App only. Explicit `--source` (or
`--backup`), child `--placements` and isolated `--out` are required. Its default
authoring path prepares selected assets without generating a child manifest or
another preview sheet. `--legacy-scene 1` retains the original full-scene authoring
path explicitly. It is never imported by runtime or normal installer setup.

About owns campus credits and actual resolved release adaptation over shared
About. Owner-local documentation/research stays with App, each content owner,
Tour, About or club according to its subject. No empty media/docs/research repo
was created. Project code AGPL-3.0 does not relicense Regents photographs or OSM
placement data. Future accessibility, ordinary photos, narration and video remain
unfinished; current keyboard/text descriptions must be preserved.

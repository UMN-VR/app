# UMN campus App

Shared Campus runtime/shell/composition/build/optional authoring tools; injected scene catalogue with no child imports.

Independent sibling repository. Prepared public releases do not require the private backup. Source extraction and checks are queued; see [owner instructions](AGENTS.md).

The [independent scene guide](docs/independent-scenes.md) records ownership,
prepared content and remaining public contracts. `mountCampusApp` receives the
route catalogue and qualified borrowed native host. It creates the Campus content,
fixed thirteen-tab shell, About and optional Dev composition once. Report-only
startup bypasses native preparation; cleanup settles pending work before releasing
borrowed resources. No child content or Earth website wrapper is imported.

Public entry points include browser composition, route build configuration,
exact App/legacy artifact verification and optional authoring. The actual native
browser factory, checked scene producer and worker/update producer are still
requested from their owners. A typed injected host is not a passing browser
receipt. Source tests/declarations/lint/build/pack remain unrun while queued.
